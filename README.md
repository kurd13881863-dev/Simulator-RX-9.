# Simulator RX-9 — Android APK via GitHub Actions

1. Create a GitHub repository and upload the contents of this folder.
2. In the repository, open **Actions** and allow workflows if prompted.
3. Run **Build Android APK** (or push to the main branch).
4. When it finishes, open the run and download the `Simulator-RX-9-APK` artifact.

The workflow builds a debug APK. The icon source image is included as `icon.png`; Android launcher icon generation can be completed in Android project resources if needed.
